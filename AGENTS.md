# Agent context

**Read [`CLAUDE.md`](./CLAUDE.md) at the repo root — it is the canonical, tool-agnostic
source of truth for this project.**

That file covers what Connectify is, key commands, architecture rules that are load-bearing,
how to navigate the code, deployment, which secrets live outside git, and a Working log of
recent changes and current state.

This repo is worked on from more than one AI tool (Claude Code, Codex, others). Do not fork
the context into tool-specific files: keep `CLAUDE.md` as the one shared document, and when
you finish meaningful work, add an entry to its **Working log** (newest first: date, which
tool, what changed, current state) so the next session can resume cold.
